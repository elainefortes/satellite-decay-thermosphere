## Scientific and technical findings

1. The observational outcome is a 180-day SATCAT cataloged decay indicator.
   Four same-day ambiguous records are excluded. A controlled disposal cannot
   be distinguished from other cataloged decays by these labels alone.
2. The SATCAT snapshot date of 2026-10-31 is an assumption. The available
   evidence does not independently establish its provenance. The release
   preserves the assumption, marks it PENDING and never silently claims proof.
3. A stratified random test split reproduces the archived 9,604/3,202 split.
   Mean-motion and perigee features are correlated. The model is not tested
   on a prospective time split.
4. The held-out RF AP (~0.7752), AUC (~0.9349) and Brier (~0.02215) are
   historical results, not measurements from executing this new package.
   Average predicted probability (~0.0963) exceeds observed frequency
   (~0.0315). Interpret model probabilities cautiously.
5. Transfer between Starlink and other satellite populations is weaker
   than the random holdout. The perigee baseline can outperform RF in the
   cross-population experiments.
6. Bootstrap intervals are computed on fixed held-out predictions; they do
   not include uncertainty from refitting the entire training pipeline.
7. Four orbital K-Means clusters were retained for interpretation. This
   does not maximize the measured silhouette score. Isolation Forest top
   percentiles are selection quotas, not physically validated anomalies.
8. The fixed-Ap NRLMSIS experiment uses pointwise calculations because the
   batch configuration returned non-finite values in the audited runtime.
9. The May 2024 storm calculation compares historical three-hour indices
   against an Ap=4 reference at 2,160 sampled points. This is a modeled
   atmospheric counterfactual, not a trajectory propagation. Input indices
   are now required as a frozen source; dynamic fetching was removed.
10. WACCM-X is interpolated in altitude and solar flux. SSP5-8.5 for 2100
    is left unavailable. Density-factor changes are not orbital-decay times.
11. The original export used an internal Colab notebook API. The release
    removes it; standard file download or GitHub commit is recommended.
12. Notebook and manuscript are not yet a fully self-contained publication
    package: only three atmospheric figures are generated by the notebook.
13. The complete source datasets and the frozen seven-component Ap input are
    not all available in this execution environment; a full clean run was
    not possible here.
